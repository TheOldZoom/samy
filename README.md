## About

Samy is an open-source Discord bot built for moderation, server management, utilities, and fun.

## Features

- **Moderation** - ban, kick, mute, jail, warn, purge, lockdown, and moderation cases
- **Server Management** - welcome and leave messages, link previews, and server configuration
- **Message Builder** - create messages, embeds, and Components V2
- **Utilities** - weather, translation, timezones, unit conversion, colors, and text tools
- **User and Server Info** - view profiles, avatars, banners, emojis, and server information
- **Social** - AFK statuses, marriages, adoptions, family trees, and user shipping
- **Fun** - memes, jokes, facts, cats, and dogs

and more..

## Tech Stack

Samy is built with:

- **[TypeScript](https://www.typescriptlang.org/)** - language
- **[Bun](https://bun.sh/)** - runtime and package manager
- **[Discord.js](https://discord.js.org/)** - Discord API wrapper
- **[Prisma](https://www.prisma.io/)** - ORM
- **[PostgreSQL](https://www.postgresql.org/)** - database
